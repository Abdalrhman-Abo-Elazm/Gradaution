# Academy - منصة المواد الدراسية

منصة تعليمية باللغة العربية لإدارة المواد الدراسية والمستندات.

## الميزات

- 📚 رفع وإدارة المواد الدراسية (PDF, TXT)
- 👤 نظام تسجيل دخول وإنشاء حسابات
- 📁 استرجاع الملفات المرفوعة وتنظيمها حسب المادة
- 🎓 عرض قائمة الدورات الدراسية

## متطلبات التشغيل

- Node.js (v14 أو أحدث)
- npm

## التثبيت والتشغيل

1. **الانتقال إلى مجلد الخادم وتثبيت التبعيات:**
   ```bash
   cd backend
   npm install
   ```

2. **إعداد متغيرات البيئة:**
   أنشئ ملف `.env` بجانب `server.js` وأضف:
   ```
   JWT_SECRET=your-super-secret-jwt-key
   PORT=3000
   ```

3. **تشغيل الخادم:**
   ```bash
   npm start
   # أو للتطوير
   npm run dev
   ```

4. **فتح واجهة المستخدم:**
   افتح `frontend/INDEX.html` في المتصفح أو شغّل خادم محلي للملفات الثابتة.

## API Endpoints

### Authentication
- `POST /api/register` - إنشاء حساب جديد
- `POST /api/login` - تسجيل الدخول

### Files
- `POST /api/upload` - رفع ملف (يتطلب مصادقة) مع تحديد المادة ونوع الملف (`material` أو `exam`)
- `GET /api/files` - استرجاع ملفات المستخدم

### Courses
- `GET /api/courses` - استرجاع قائمة الدورات

### Chat API
- `POST /api/chat` - إرسال نص إلى نقطة النهاية الخارجية HF وعودة الاستجابة.
  - body JSON: `{ "inputs": "نص الاختبار" }`

## اختبار نقطة النهاية

يمكنك اختبار نقطة النهاية المحلية مباشرة من خلال `curl` أو أدوات مثل Postman:
```bash
curl -X POST http://localhost:3000/api/chat \
  -H "Content-Type: application/json" \
  -d "{ \"inputs\": \"اكتب لي ملخصًا قصيرًا عن الشبكات اللاسلكية\" }"
```

أو استخدم صفحة الاختبار المدمجة بفتح `frontend/INDEX.html` والنقر على "اختبار الـ API".

## قاعدة البيانات

يستخدم التطبيق SQLite لتخزين:
- بيانات المستخدمين
- معلومات الملفات
- قائمة الدورات

## الأمان

- تشفير كلمات المرور باستخدام bcrypt
- مصادقة JWT للجلسات
- التحقق من صحة الملفات المرفوعة

## التطوير

```bash

```

سيتم إعادة تشغيل الخادم تلقائياً عند تغيير الملفات.
